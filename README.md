# Kaboo Seamless Image Maker

PNG / 画像をブラウザだけでシームレス（タイル可能）画像へ変換する、依存ライブラリなしの Web ツールです。

## 特徴

- ないよ……そんなもの……

## 起動

`index.html` を Chrome / Edge / Firefox などで開いてください。
ローカルファイルとして開いても、通常の Web サーバーに置いても動作します。

## 入力方法

- 「読み込み」ボタン
- エクスプローラー等からドラッグ＆ドロップ
- クリップボードの画像を `Ctrl+V`

## 方向

- 横のみ: 左右端をつなげる
- 縦のみ: 上下端をつなげる
- 縦横: 四辺をつなげる

## アルゴリズム

### 1. 50% Offset + Feather（既定）
選択方向へ画像を 50% 循環シフトし、元の端を中央へ移動します。その中央シーム上へ元画像をフェザー合成し、外周は循環シフト由来の連続した画素列として残します。草、砂、岩、地面など写真系テクスチャ向けです。

### 2. Opposite Edge Blend
指定したボーダー幅の左右端／上下端を、反対側の対応画素と対称に混ぜます。中心部分は変更しません。端同士がすでに近い画像の微修正に向きます。

### 3. Tone Match + Edge Blend
左右または上下の指定ボーダー帯の平均色差を測り、差を画像全体へ線形ランプとして分散してから Opposite Edge Blend を実行します。照明の偏りや色かぶりがある写真向けです。

### 4. Mirror 2× Tile
元画像と反転コピーを連結します。選択方向の出力サイズは 2 倍になります。境界は同一画素同士が接するため確実に連続しますが、鏡像対称が目立つことがあります。

## ボーダー幅

- `%`: 横方向は画像幅、縦方向は画像高に対する割合
- `px`: 各辺からの固定ピクセル数

Mirror 2× Tile ではボーダー幅を使用しません。

## フェード曲線

- Smoothstep: 境界の傾きが穏やか。既定。
- Cosine: Smoothstep に近い滑らかな変化。
- Linear: 一定速度のブレンド。

## 自動変換について

画像を読み込むと自動で変換されます。また、方向・アルゴリズム・ボーダー幅・フェード曲線を変更すると、自動で再変換されます。

## 比較表示の操作

- 初期倍率は、画像全体がプレビュー領域に収まる倍率に自動調整
- PC: マウスホイールで拡大縮小、ドラッグで移動、プレビュー領域のダブルクリックで全体表示にリセット
- スマホ / タブレット: 1本指ドラッグで移動、2本指ピンチで拡大縮小
- 画面右下の `－ / 全体 / ＋` ボタンでも操作可能

## ファイル構成

- `index.html` — UI
- `styles.css` — スタイル
- `seamless-core.js` — 画像処理本体
- `app.js` — 読み込み、貼り付け、プレビュー、保存などの UI ロジック
- `ALGORITHM_NOTES.md` — アルゴリズム調査メモ

## 補足

「シームが消える」ことと「反復模様が目立たない」ことは別問題です。特徴的な物体や強い明暗ムラがある写真では、3×3 タイルプレビューで周期感も確認してください。


## 3×3タイル表示について

3×3タイルプレビューは、1枚あたり **最大1024px** までの解像度で生成します。つまりキャンバス全体の上限は **3072px × 3072px** 相当です。これにより、従来より大きく拡大しても確認しやすくしつつ、極端なメモリ消費も避けます。
